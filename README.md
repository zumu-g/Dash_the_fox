# Dash the Fox

A fun platformer game for iPad and iPhone, built with Swift Playgrounds and SpriteKit.

## About

Dash the Fox is a side-scrolling platformer where you play as an adorable orange fox named Dash. Jump across platforms, collect coins, avoid enemies, and reach the goal flag to win!

## Features

- Cute fox character with animated design
- Touch controls optimized for mobile:
  - Left/Right arrow buttons for movement
  - Jump button for jumping
- Collectible coins with bobbing animation
- Purple slime enemies that patrol back and forth
- Multiple platforms to navigate
- Lives system (3 hearts)
- Win and Game Over screens
- Camera that follows the player

## How to Play

1. Open the project in Swift Playgrounds on iPad or Mac
2. Tap "PLAY" to start the game
3. Use the arrow buttons on the left to move Dash
4. Tap the JUMP button on the right to jump
5. Collect coins for points
6. Avoid the purple enemies
7. Reach the red flag at the end to win!
